# Git Commit Message Generator

Reference implementation for the "Git Commit Message Generator" Mini
Project in Sypher's `build-with-ai` course. A CLI that reads a `git diff`
and returns a conventional commit message, generated by Claude Haiku.

This is the finished, verified version -- type the lesson's own steps
yourself first; come back here to compare your output or see it run.

## Setup

```bash
python -m venv venv
source venv/bin/activate   # venv\Scripts\activate on Windows
pip install -r requirements.txt
cp .env.example .env       # then add your ANTHROPIC_API_KEY
```

## Run

```bash
git diff | python commit_gen.py
git diff | python commit_gen.py --type feat --copy
python commit_gen.py --diff-file some.diff
```
